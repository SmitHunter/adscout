# AdScout M3 — GUI v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. UI tasks (5–9) must load `frontend-design:frontend-design` before writing UI code.

**Goal:** `uv run adscout` opens `http://localhost:8787`. In the browser you search a keyword, watch live progress, and land on a product report: Winner Score, factor rulers, launch timeline, creative gallery with locally downloaded media, an advertiser leaderboard, and tick/untick relevance. It should look like a product people would pay for.

**Architecture:**
- **Backend:** FastAPI (`adscout.api`) wraps the existing services. A `SearchManager` runs one scrape at a time in the server's event loop and fans progress out to SSE subscribers. Reports come from one `Report` model built by `services/report.py`. Media is downloaded after each scrape into `data/media/<snapshot_id>/`, and near-duplicate creatives are merged by perceptual hash.
- **Frontend:** a Vite + React + TypeScript app in `web/`. API types are generated from FastAPI's OpenAPI schema. The app builds into `src/adscout/static/`, which FastAPI serves.

**Tech Stack:**
- **Backend:** FastAPI, uvicorn, sse-starlette, Pillow, imagehash.
- **Frontend:** Vite, React 19, TypeScript (strict), Tailwind CSS v4, shadcn/ui, TanStack Query, React Router, Recharts, Vitest + Testing Library, ESLint + Prettier, openapi-typescript.
- **Fonts:** `@fontsource-variable/archivo` and `@fontsource/martian-mono`, bundled so they work offline.

**Spec:** `docs/superpowers/specs/2026-10-17-adscout-design.md` and `docs/build-prompt.md` (sections "Search", "Product report", "Design direction", "Quality bar"). Follow-ups: `docs/plans/2026-10-17-m1-followups.md` (M3 sections from both M1 and M2), covered by Tasks 1–3.

## Global Constraints

- **Python:** 3.12, mypy strict on `src/`, ruff check + `ruff format --check src tests` clean, pytest offline. Don't run `ruff format` over `docs/`.
- **Frontend:** TypeScript `strict: true` with `noUncheckedIndexedAccess`. ESLint + Prettier clean. `npm --prefix web run build` writes to `src/adscout/static/`, which stays gitignored. Vitest runs offline.
- **Run:** `uv run adscout` (no subcommand) = `adscout serve`. It binds `127.0.0.1:8787` and opens the default browser unless `--no-open`. If `src/adscout/static/index.html` is missing, it prints `Frontend not built. Run: npm --prefix web ci && npm --prefix web run build` and still serves the API.
- **Times:** stored UTC. The API returns ISO-8601 UTC strings. The UI formats them in the timezone from `GET /api/settings` (default `Australia/Melbourne`).
- **Politeness:** one search at a time. `POST /api/searches` while one is running → HTTP 409 `{"detail": "A search is already running. Wait for it to finish or cancel it."}`. Media download is sequential with a 0.3–0.8 s randomised gap, per-file cap 30 MB, skipped (not failed) on error.
- **Security:** bind localhost only. No CORS in production. In dev, the Vite proxy forwards `/api` and `/media`. The media route serves only files under `data/media/` (guard against path traversal).
- **Design tokens** (the only colours and fonts the UI uses; defined as CSS variables in `web/src/styles/tokens.css`):

  | Token | Dark | Light | Use |
  |---|---|---|---|
  | `--bg` | `#0E1418` | `#EEF2F4` | page |
  | `--panel` | `#141C21` | `#FFFFFF` | panels |
  | `--rule` | `#24323B` | `#D3DCE1` | 1px rules, tracks |
  | `--text` | `#DCE5EA` | `#0F181D` | primary text |
  | `--muted` | `#7D909B` | `#5A6B75` | secondary text |
  | `--signal` | `#55C7BE` | `#0E7872` | brand/interactive, leader series |
  | `--pass` | `#3DBA7E` | `#157C54` | pass chip |
  | `--warn` | `#E3A23B` | `#975F06` | warn chip |
  | `--fail` | `#E05D62` | `#B8373D` | fail chip |

  - **Type:** Archivo variable for all UI text. Use width 75–87 for dense tables and the gallery data strip, and 100 elsewhere. Martian Mono is for numerals only (scores, counts, dates, IDs), with `font-variant-numeric: tabular-nums`.
  - **Scale (px):** 12 / 13 / 15 / 18 / 24 / 40 / 72. The 72 is only for the headline score.
  - Sentence case everywhere: no all-caps labels, no letter-spaced eyebrows, no middle-dot meta strings (use separate columns or spacing), no `→` on buttons, no emoji.
  - **Radius:** 2px on inputs and buttons, 0 on panels. Hierarchy comes from rules and spacing, not shadows. One shadow is allowed, on popovers only.
- **Memorable element:** the factor ruler. Each factor is a horizontal track with tick marks at its fail and pass thresholds, and at full where it exists. A marker sits at the value and is coloured by status. It shows "value vs threshold" without reading a number. Everything around it stays quiet.
- **Motion:** only one orchestrated moment. On report load, the score counts up over 600 ms and the ruler markers slide to their values over 400 ms. Respect `prefers-reduced-motion` (no animation). There are no hover animations on cards.
- **Layout:**
  - Fully usable at 1366×768.
  - The gallery is 4 columns at ≥1280 px, 3 at ≥1024 px, and 2 at ≥768 px.
  - Below 768 px a single column is acceptable.
  - Visible keyboard focus (2px `--signal` outline). All controls are reachable by keyboard.
- **Copy (exact):**
  - Empty home: `Search a product to see if it's a proven winner.` plus a suggestion button `Try "posture corrector" in US`.
  - Progress: `Found {n} ads from {a} advertisers` plus phase text `Opening the Ad Library` / `Scrolling for more ads` / `Downloading media` / `Done`.
  - Blocked: `Meta asked for login.` (or the source's reason) plus the how-to-fix text plus the button `Open browser`.
  - 409 toast: the API detail text.
- **Commits:** end with a blank line + `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Navigating away or reloading during a search:** the search keeps running server-side. Reopening the home page shows the active search's live progress, rebuilt from the manager's last event. Tests in Tasks 2 and 6.
2. **Server restart with a snapshot stuck in `running`:** on startup it is marked `error` with message `Interrupted: AdScout was closed during this search.` Test in Task 2.
3. **CDN media already expired, or the download fails:** the gallery shows a neutral placeholder tile with the text `Media unavailable` and the ad still counts. Tests in Tasks 3 and 8.
4. **Untick or re-tick in the gallery or leaderboard:** the score, factors and timeline update after the mutation without a full reload, and the change survives re-running the same search. Tests in Tasks 4 and 8.
5. **Snapshot with zero ads, or status error/blocked:** the report page renders the reason and a `Search again` action, with no blank charts and no crash. Tests in Tasks 1 and 7.

### Task 2: SearchManager (one search at a time, live events, startup sweep)

- Test: `tests/services/test_searches.py`, `tests/services/test_run_scrape.py`

**Interfaces:**
- Produces:
  - `scrape.py` is split. `start_snapshot(engine, q, source_name) -> int` creates the snapshot up front. `run_scrape_into(engine, snapshot_id, q, source, progress, cancel) -> Snapshot` runs the search. The old `run_scrape` becomes a thin wrapper over both, so the CLI behaves as before.
  - `SearchEvent(BaseModel)`: `snapshot_id: int`, `kind: Literal["progress", "media", "done", "blocked", "error", "cancelled"]`, `ads_found: int`, `advertisers: int`, `phase: str`, `message: str | None`.
  - `class MediaStep(Protocol)`: `async download_snapshot(engine, snapshot_id, progress, cancel) -> int` (Task 3's `MediaDownloader` implements it).
  - `class SearchManager` with `__init__(engine, source_factory: Callable[[SearchQuery], Source], media: MediaStep | None)`. Methods:
    - `async start(q) -> int` raises `SearchBusy` if one is running.
    - `cancel(snapshot_id) -> bool`.
    - `active() -> SearchEvent | None` returns the last event of the running search.
    - `subscribe(snapshot_id) -> AsyncIterator[SearchEvent]` yields the latest event first, then live events, and ends after a terminal kind. A finished snapshot yields one terminal event built from the DB.
  - One `asyncio.Lock` per manager instance, created lazily in its loop. This replaces the module-level lock (M1 follow-up).
  - `MetaWebSource` sleeps through a cancel-aware wait: `asyncio.wait_for(cancel_event.wait(), delay)`. `CancelToken` gets an `asyncio.Event`. Cancel takes effect in under 1 s, including during `driver.open`, which is wrapped so a cancel closes the browser.
  - `repo.sweep_running(session) -> int` marks `running` snapshots `error` with message `Interrupted: AdScout was closed during this search.`
  - Phase text mapping (exact): opening → `Opening the Ad Library`, scrolling → `Scrolling for more ads`, media → `Downloading media`, done → `Done`.

### Task 3: Media download + perceptual-hash grouping

**Files:**
- Create: `src/adscout/services/media.py`
- Modify: `src/adscout/scoring/creatives.py`, `src/adscout/db/repo.py`, `pyproject.toml` (add `pillow`, `imagehash`)
- Test: `tests/services/test_media.py`, `tests/scoring/test_creatives.py`

**Interfaces:**
- Produces:
  - `MediaDownloader(media_dir: Path, client: httpx.AsyncClient | None = None, sleep=asyncio.sleep, rng=None, max_bytes=30_000_000)`.
  - `async download_snapshot(engine, snapshot_id, progress: Callable[[int, int], Awaitable[None] | None] | None, cancel: CancelToken | None) -> int` returns the number of files saved.
  - Per ad, per `MediaItem`: images save the `url`; videos save `preview_url` as the poster and the video file itself, subject to the cap.
  - Files go to `media_dir/<snapshot_id>/<ad_archive_id>_<n>.<ext>`, with the extension taken from the `Content-Type`.
  - It updates `local_path`, stored relative to `media_dir`, and `phash` (the hex of `imagehash.phash`) for images and posters. It writes back to `AdRow.media` JSON.
  - Downloads are sequential with a 0.3–0.8 s gap. Errors and over-cap files are skipped and logged at warning without the URL query string.
  - `creatives.group_creatives` second pass: merge groups whose representative phash (first image or poster with a phash) has Hamming distance ≤ 6. The merged key is the lexicographically smaller one. Groups without a phash never merge by hash.
  - `Settings.media_dir` is a property: `data_dir / "media"`.

**Interfaces:**

  - `GET /api/settings` → `{timezone, max_results, has_meta_token: bool, version}`
  - `GET /api/snapshots?keyword=` → `list[SnapshotView]`, newest first
  - `POST /api/searches` body `SearchQuery` → `201 {"snapshot_id": int}`, `409` busy, `422` invalid (pydantic message)
  - `GET /api/searches/active` → `SearchEvent | null`
  - `GET /api/searches/{id}/events` → SSE (`event: <kind>`, `data: SearchEvent JSON`), via sse-starlette. 15 s ping.
  - `POST /api/searches/{id}/cancel` → `{"cancelled": bool}`
  - `GET /api/snapshots/{id}/report` → `Report`, `404` with `{"detail": "Snapshot {id} not found."}`
  - `PUT /api/overrides` body `{keyword, scope, target_id, mode}` → `204`. `DELETE /api/overrides` body `{keyword, scope, target_id}` → `204`.
  - `POST /api/browser/open` → opens the persistent profile headful in a background thread or task. Returns `202`, or `409` if a search is running.
  - `GET /media/{snapshot_id}/{filename}` → `FileResponse`. Only `[A-Za-z0-9_.-]` filenames inside `media_dir/<id>/`, else 404.
  - Static: if `static_dir/index.html` exists, mount assets and serve `index.html` for any non-`/api` and non-`/media` path (SPA fallback).
  - All JSON uses `by_alias=True`, so `threshold.pass` is used.
- CLI: `adscout serve [--port 8787] [--no-open]`. The app callback with no subcommand runs serve. Uvicorn on `127.0.0.1`. `webbrowser.open` fires after startup unless `--no-open`.
- `npm run gen:api` (Task 5) reads `GET /openapi.json`. A Python script `scripts/dump_openapi.py` writes `web/openapi.json` without starting a server, so codegen works offline.
